# ToDoList

Учебный REST API на Go для списка задач. Можно создавать пользователей, добавлять им задачи, менять их и отмечать выполненными. Данные хранятся в PostgreSQL.

Ещё есть статистика: сколько задач создано и выполнено, процент выполненных и среднее время выполнения. Её можно посмотреть для отдельного пользователя и за нужный период.

## Что использовал

- Go и стандартный `net/http`
- PostgreSQL, для работы с базой — `pgx`
- Docker Compose
- Swagger для документации и проверки запросов
- Zap для логов

## Как запустить

Нужны Docker с Compose и `make`. Все команды выполняются из корня проекта.

Создать файл `.env`. Например, для локального запуска:

```env
POSTGRES_USER=todoapp
POSTGRES_PASSWORD=todoapp
POSTGRES_DB=todoapp

HTTP_ADDR=:5050
HTTP_SHUTDOWN_TIMEOUT=30s
LOGGER_LEVEL=DEBUG
POSTGRES_TIMEOUT=10s
```

Поднять базу:

```bash
make env-up
```

Когда PostgreSQL будет готов принимать подключения, применить миграции и запустить приложение:

```bash
make migration-up
make todoapp-deploy
```

API будет доступен по адресу `http://localhost:5050/api/v1`.
Swagger: [http://localhost:5050/swagger/index.html](http://localhost:5050/swagger/index.html).

## Что есть в API

| Метод | Путь | Что делает |
| --- | --- | --- |
| POST | `/users` | Создать пользователя |
| GET | `/users` | Получить список пользователей |
| GET | `/users/{id}` | Получить пользователя |
| PATCH | `/users/{id}` | Изменить пользователя |
| DELETE | `/users/{id}` | Удалить пользователя |
| POST | `/tasks` | Создать задачу |
| GET | `/tasks` | Получить список задач |
| GET | `/tasks/{id}` | Получить задачу |
| PATCH | `/tasks/{id}` | Изменить задачу |
| DELETE | `/tasks/{id}` | Удалить задачу |
| GET | `/statistics` | Получить статистику задач |

Все пути в таблице начинаются с `/api/v1`. У списков есть параметры `limit` и `offset`, у статистики — `user_id`, `from` и `to`. Даты передаются в формате `YYYY-MM-DD`.

Сначала нужно создать пользователя, а потом передать его `id` в поле `author_id` при создании задачи. Чтобы отметить задачу выполненной, отправить PATCH с телом:

```json
{
  "completed": true
}
```

## Структура проекта

- `cmd/todoapp` — запуск приложения
- `internal/core` — общие типы, настройки, HTTP-сервер и подключение к базе
- `internal/features` — пользователи, задачи и статистика; внутри обработчики, сервисы и запросы к базе
- `migrations` — SQL-миграции
- `docs` — сгенерированная документация Swagger

## Полезные команды

```bash
go test ./...           # запустить тесты (нужен Go версии из go.mod или новее)
make swagger-gen       # обновить Swagger после изменения аннотаций
make todoapp-undeploy   # остановить приложение
make env-down          # остановить базу
```
